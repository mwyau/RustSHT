# Scaled-packet SIMD in reflected native-f32 spin synthesis — rejected

This follow-up tested the Callgrind finding from V1: use the existing checked `try_accumulate_f32_scaled_synthesis_packet` helper instead of four scalar complex scaling calls for each full-width scaled packet in the reflected spin-1 leaf. Even coefficient rows use `(even=coefficient, odd=0)` and odd rows use `(even=0, odd=coefficient)`. Partial tails keep the existing exact scalar path. If a full packet is unsafe or nonfinite, the leaf declines the entire block before committing any output.

Candidate relative-L2 error versus DUCC remained worse than parent in every cell (candidate `1.949e-4–2.140e-4`; parent `1.415e-4–1.426e-4`). q8 regressed repeatably, so the candidate was not extended to 15 pairs or promoted. ## Route and safety evidence

The route test showed every attempted reflected block succeeded: full q1/q8 `2841/2841` and `8050/8050`, reduced `905/905` and `2685/2685`, with zero block declines. A new focused unit test passed exact scalar comparison for even and odd scaled rows, including subnormal and large exponents. The route counters do not count individual scaled packet helper calls. The whole-call workers passed finite, repeated-call, and poisoned-output reset checks.

The V1 profile attributed over half of candidate Ir to the prior scalar scaling helpers; V2 replaces those calls on checked full packets but still enters the helper once per coefficient row. Source inspection shows each invocation repeats cosine/basis loads, exponent splitting and range checks. The rejected V2 patch, complete paired results, and previous V1 Callgrind/assembly are preserved here and in the [V1 diagnosis](../f32-spin1-native-f32-reflected-leaf-v1/README.md). No V2 Callgrind or broader independent analytic/adjoint/extreme matrix was run because the q8 performance gate failed.

## Decision and next hypothesis

Reject V2 and do not promote the V1 leaf. Preserve the shared recurrence and exact scalar tail/unsafe path. A separate bounded V3 test may fuse all four scaled coefficient rows into one checked packet operation, sharing basis/cosine loads and exponent decomposition across both spin channels. This is justified only as a substantive reduction of the repeated helper work already measured in V1; require a material whole-call gain and q8 non-regression before extending validation. M6 remains open.
