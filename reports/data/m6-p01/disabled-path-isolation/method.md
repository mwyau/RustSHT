# P01 compiled-path isolation screen

The comparison variant is built from the current candidate working tree and changes only the scalar synthesis call-site gate `transition_enabled` in `src/transform.rs` from its normal `lmax >= SCALAR_TRANSITION_MIN_LMAX && T::supports_paired_scalar()` condition to `false`. This disables invocation of the P01 scalar transition and lets the already-present general visitor path handle the same work. All other C02/C03 production source remains unchanged. The original `src/transform.rs`, candidate patch, and candidate/baseline binaries are preserved. After compilation, the exact working-tree source file is restored before any timing runs. The spin1 comparison uses six alternating fresh-process baseline/disabled-variant pairs, T511, GL STANDARD f64, `ntheta=512`, `nphi=1024`, full `mmax=511`, `phi0=0.37`, q1, both operations, and requested-only mode. Each process records five samples per operation on CPU core and a preflight snapshot. A separate one-process scalar T1023 q1 synthesis-only check uses GL, f64, `ntheta=1024`, `nphi=2048`, full `mmax=1023`, `phi0=0.37`, and requested-only mode.
