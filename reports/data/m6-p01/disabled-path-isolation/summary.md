# P01 compiled-path isolation screen

The disabled variant was built from the candidate working tree. Its only source difference was changing the scalar `transition_enabled` gate in `src/transform.rs` to `false`; the retained [patch](disabled-p01-only.patch) shows that one-line change. This prevents calls to the P01 scalar transition while leaving the rest of the candidate C02/C03 source and the visitor fallback in place. The optimized scalar transition symbol is present in the candidate binary and absent from the disabled binary. The disabled binary text section is 28,560 bytes smaller than candidate. The original `src/transform.rs` was restored byte-for-byte after the build (SHA-256 `6ea8c4624652e7c203c5e14e81891b1c335e82c3b48b95f9eec0c958fdd2797e`). The baseline and candidate binaries remain unchanged at SHA-256 `4fd894d46b7195d8a7a4c24cc52f3f04a85ccd1c213d5a2c896f7c828156ccd0` and `3388c0219a9d9ba214241763bd8749a35ef6e60bbe685ec779b842291ff6da2e`. Disabled variant binary SHA-256 is `6cf38c349bc8382ceeffa5d60fb6e8d8963ebbbaf3b87ebd6e50d7d8fd7f375f`. Six alternating baseline/disabled fresh-process pairs were run for T511 spin1 q1, with five samples per operation. The synthesis disabled/baseline median paired ratio is **0.98818** (95% paired bootstrap interval **0.97552–0.98968**), a 1.18% improvement; all six paired ratios are below 1. The analysis ratio is **0.99081** (interval **0.96362–0.99477**). Thus the >2% spin1 synthesis slowdown seen against the candidate disappears when the compiled scalar path is removed. Since the spin1 algorithm is untouched, this points to an indirect code-size/layout/code-generation effect or timing variability associated with the scalar path; it is not evidence that spin1 invokes the transition. The single disabled-variant scalar T1023 q1 synthesis check had a five-sample median of **298.385 ms**, versus the prior baseline median **296.153 ms** and candidate median **197.335 ms**. It is 0.75% slower than baseline and confirms that the P01 scalar synthesis gain is absent in the disabled variant. All scalar samples are in `scalar-synthesis-check.csv`; all paired numerical samples are in `process-pairs.csv`. Structured timing and memory summaries are retained; raw stdout, GNU-time output and process captures remain local and untracked. The build log has one expected unused-constant warning because disabling the call-site gate also leaves `SCALAR_TRANSITION_MIN_LMAX` unused in this temporary build. This diagnostic result does not decide acceptance.
