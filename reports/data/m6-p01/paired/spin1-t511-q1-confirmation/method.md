# T511 spin1 q1 confirmation

Six additional alternating fresh-process baseline/candidate pairs use the saved binaries recorded in the adjacent SHA-256 files. Every process runs the existing `m1b_bench` CLI with spin=1, T511, GL STANDARD f64, `ntheta=512`, `nphi=1024`, full `mmax=511`, `phi0=0.37`, q1, both whole-transform operations, and requested-only mode. Each operation records five samples. CPU affinity is one CPU core. `run-one.sh` checks CPU pressure and competing build/benchmark processes before each run. Detailed host captures remain local and untracked. The report retains paired timings and peak-RSS summaries; raw stdout and GNU-time output remain local and untracked. Odd pairs run baseline first; even pairs run candidate first. Ratios are candidate/baseline ratios of per-process five-sample medians, paired by pair number. The summary uses the median paired ratio and a deterministic 50,000-resample percentile bootstrap (Python `random.Random(20261017)`, linear percentile interpolation). All six pairs are retained.
