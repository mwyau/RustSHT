# P02 precomputed-coefficient visitor screen

This screen compares the one-time prepared-coefficient reuse candidate with the retained pre-P01 native baseline. It covers full-transform scalar synthesis at T1023 and T2047, plus the T511 scalar and spin-1 q1 controls. Each complete synthesis and analysis call is gated separately. Each cell has six fresh-process pairs, with baseline-first and candidate-first order alternating. Every process uses GL STANDARD f64, `phi0=0.37`, full `mmax=L`, `ntheta=L+1`, `nphi=2*(L+1)`, one requested Rayon thread, requested-only mode, one warm-up and five measured samples for synthesis and analysis. CPU affinity is one CPU core. `/usr/bin/time -v` records elapsed process time and peak RSS. `run-one.sh` performs local pressure and interference checks before each process and refuses a run when it detects a concurrent compiler/benchmark workload or unrelated CPU-intensive activity. Raw host and process records remain local and untracked; the committed summary retains only the validity decision. `summarize.py` keeps every retained sample and computes median candidate/baseline ratios and deterministic 95% pair-bootstrap percentile intervals with seed 20261017. The candidate change reuses the already prepared even/odd coefficient arrays in the scalar paired visitor fallback. The coefficients are computed once per order before blocks, in the same degree-pair layout and arithmetic as the former repeated computation. No recurrence, summation order, overflow guard or fallback condition changes. The baseline binary is `target/m6-p01-baseline-bench`, the pre-P01 executable used in the P01 screen. Results therefore evaluate the current P02+P01 working-tree candidate against that retained pre-P01 control; they do not isolate the incremental P02 effect from the previously measured P01 change. P01 remains unaccepted. Correctness checks before the screen:

- `cargo test --release --lib scalar_synthesis_matches_independent_low_degree_harmonics -- --nocapture`
- `cargo test --release --lib scalar_synthesis_matches_ducc_0410_reference -- --nocapture`
- `cargo test --release --lib t255_mixed_synthesis_matches_ducc_0410_samples -- --nocapture`
- `cargo fmt --all -- --check`
