# Compact tables on over-resolved GL grids

## Investigation plan

`ScalarLegendreTable::supported_layout` currently requires `ntheta = lmax + 1`. This excludes the atmospheric full Gaussian T63 (`96x192`) and T85 (`128x256`) grids from table selection even though their nodes are symmetric Gauss–Legendre points. The table builder already stores the northern hemisphere, uses the plan's actual latitude coordinates and cutoff metadata, and rejects layouts above the 34 MiB cap. The experiment tests whether table reads repay construction and memory costs at those over-resolved geometries. The comparison will keep the complete grid fixed within each recurrence/table pair. It will use f64 GL full-band scalar and spin-1 STANDARD synthesis and analysis at T63, T72, and T85, with exact-minimum grids as controls and the atmospheric T63/T85 dimensions as the target. Rayon pools will use one and eight workers. Each case will use identical coefficients or map values, `phi0=0.37`, process-isolated paired runs, reusable plan/workspace timing, and separate cold construction/first-call and warm samples. The table candidate will be forced only by a temporary private benchmark control; no public override will be added. The temporary eligibility prototype will permit symmetric GL layouts with `ntheta >= lmax + 1` and test T63 below the current table floor. It will keep the 34 MiB cap, table input-safety guard, existing polar cutoffs, and scaled recurrence fallbacks. Numerical checks will compare recurrence and table outputs for synthesis, analysis, both adjoints, adjoint identities, DUCC 0.41.0 references, nonzero `phi0`, and extreme finite fallback. CC/F1 and f32 remain recurrence controls. The source prototype will be removed unless repeated process measurements show a whole-transform gain that repays first-use cost at the stated transform counts without exceeding the memory cap. The current source is `d13a8f2` on `main`; the prior exact-grid table study and its raw data are in [the adaptive strategy report](adaptive-legendre-strategy-2026-10-14.md). CPU, compiler, build flags, exact dimensions, samples, RSS, and test outcomes will be added after the experiment.
