The symmetric order group accounts for 94.32%/81.37%, including the fused paired block at 86.28%/59.81%; forward FFT is 5.68%/18.61%, pair preparation 2.96%/7.46%, and factor fill 1.24%/3.36%. These are inclusive call-tree shares, not additive stage costs. Candidate totals are 691,336,065/265,147,211 Ir, reductions of 3.42%/4.82%. Hardware `perf stat`/`perf record` are blocked (`perf_event_paranoid=4`), so Ir is not cycles.

The ordinary two-degree SIMD loop is the measured target. Parent AVX2 code emits four per-vector slice-length comparisons/branches and repeated stack base reloads; zipped iteration emits one loop guard, retains the FMA sequence, and keeps bases in registers. The f32 ordinary block microbenchmark measured 45.34 ns indexed vs 27.78 ns zipped median across nine samples. This is consistent with the whole-call data but is not a substitute for it. The implementation does not alter normal/scaled arithmetic, exponent normalization, recurrence order, FFT or scheduling. Existing route traces count 266,685 scaled f32 pair calls and 159,441 factor epochs per nonzero full-q1 transform; they are counts, not elapsed-time shares. Recurrence vs accumulation vs exceptional fallback and q8 scheduling/memory-system time are not independently apportioned by this profile.
