## Dense high-band tracer details

The dense fixture stores only the nonzero f32 coefficients for m=1..16, l=600..720. The Rust tracer restores one order into a native-f32 coefficient slice and calls `prepare_order` plus the generic ordinary kernel; its `REC` records expose f32 `cos²`, a/b, prior/current state, first FMA result, second FMA result, vector-lane result, and the even/odd pair coefficients. The production source arithmetic is unchanged by the ignored test hook. Its test-only prefix observer records scaled-prefix pair count and ordinary-start degree.

DUCC's `make_ringdata` at `sht.cc:190–227` sorts rings by sine and pairs theta values summing to pi; the recurrence uses the northern member's theta, sine and cosine and retains both public output indices. `fill_a2m` at `sht_inner_loop.h:1498–1538` constructs `cos²` with `(1-sin)(1+sin)` for `|cos|>0.99`, otherwise `cos*cos`, and initializes `p1/p2`. The traced `inner_loop_a2m` at `1655–1724` calls `calc_alm2map`, then `extract_a2m` at `1541–1580` forms the reflected sums/differences and writes weighted phase coefficients. `fill_a2m` also rewrites its `almtmp` coefficient work array into even/odd pairs (`1660–1672`); the dense harness restores raw input coefficients before each ring so every ring sees identical coefficients. Passing a southern theta directly to this low-level loop would not reproduce the public reflected-ring execution.

For spin 0, `alm2leg` in `sht.cc:722–749` allocates `complex<double>` coefficient work and copies each public `complex<float>` input into it. The spin-0 `norm_l` is exactly one (`YlmBase::get_norm`, `sht_inner_loop.h:70–87`), so this is an exact widening of each input component. DUCC's dense stage trace stops after `extract_a2m` narrows the Fourier value to f32; the separate public-map traces exercise the subsequent double-buffer longitude FFT and final f32 map narrowing. Rust's direct generic high-band trace keeps recurrence, paired coefficients, sum state and Fourier output in f32, with eight AVX2 lanes. The generated AVX2 instructions contain the leading `a*cos²+b` FMA and the state-update FMA; scalar f32 `mul_add` replay matches the vector lane result.

The temporary tracer patches add observation only. They were applied in isolated checkouts; no trace hook was added to the production checkout.
