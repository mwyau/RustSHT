# M6 progress

**Current owner priority (2026-11-02):** B1 f64 is bounded; B3 f64 is primary. B0/B2 are controls; f32 performance is deferred. These checkpoints retain source-specific results.

1. **2026-11-01 — B1 hotspot profile and three candidates rejected.** At exact parent `5483faa8` (same B1 kernel blob as `8560bcae`), f32 Callgrind attributes 263.7M Ir to scaled accumulation and 146.6M to range/normalization; these are instruction counts, not cycles. Adjacent-factor reuse, range-check fusion and lazy hard-factor clearing improved isolated helpers but did not resolve a 15-pair whole-call gain. No production code was promoted. See the [hotspot package](archive/experiments/m6-b1-hotspot-profile-2026-11-01/README.md).
2. **2026-11-01 — B1 no-change normalizer bypass rejected.** The isolated f32 mixed-vector helper improved 11.6%, but only reduced q1 resolved a whole-call gain (1.2%); the other three cells were inconclusive. Parent/candidate outputs were bitwise equal. See the [normalizer package](archive/experiments/m6-b1-normalizer-nochange-2026-11-01/README.md).
3. **2026-11-02 — B1 phase profile and output-scale candidate rejected.** On source `8560bcae`, phase probes place 91–95% of f32 and 76–86% of f64 instrumented call time in Legendre plus accumulation. The f32 exponent-field output-scale shortcut had no resolved whole-call gain and enlarged the monomorphization. See the [scale-path package](archive/experiments/m6-b1-scale-output-fast-path-2026-11-02/README.md).
4. **2026-11-01 — B1 f64 seed-state normalization removed.** On `ac88fe80`, skipping the repeated lane normalization after successful SIMD seed initialization improved all four T720 calls by 3.8–6.3% over 15 pairs with byte-identical output. The protected T1023 control remains inconclusive. See the [normalizer-bypass package](archive/experiments/m6-b1-f64-normalizer-bypass-2026-11-01/README.md).
5. **2026-11-02 — B3 sampled scaled-leaf profile identifies partial exception handling.** At source `f956320c`, q1 sampled scaling estimates exceptional recovery at 3.10 ms full / 1.56 ms reduced; scalar fallback handles 25% / 39% of sampled exceptional lanes. Probe overhead is 0.4% / 0.8% in the q1 three-pair screen; q8 is noisy. The AVX2 outer specialization has a 2,696-byte frame and 186 YMM stack references, but no PMU events are available and this alone does not prove spills dominate. No production code changed. NEXT: test SIMD handling of mixed exception vectors with the existing checked scaled helper, preserving scalar fallback for unsafe products. See the [sampled-leaf package](archive/experiments/m6-b3-sampled-scaled-leaf-2026-11-02/README.md).
