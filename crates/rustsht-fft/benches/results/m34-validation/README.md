# M34 validation

The production tree was restored to the accepted M32 implementation after the three radix-five dispatch candidates were rejected. The logs in this directory record final all-feature debug and release test runs, Clippy, formatting, and a rebuild of the phase profiler. Both test profiles passed 111 tests: 37 unit, 2 across-row, 32 complex, and 40 real tests. They cover direct DFTs, Rader numerical comparisons, finite extremes, inverse normalization, f32/f64 paths, shared immutable plans, and separate workspaces for concurrent calls. The accepted M32 comparison against native and portable DUCC is recorded in [`docs/m33-final-performance-report.md`](../../../docs/m33-final-performance-report.md) and its referenced result files. The test host was an x86-64 CPU with runtime AVX2. A non-AVX2 host was not available for fallback execution. The phase profiler rebuilt successfully after a Clippy cleanup and passed direct-DFT validation for N=723 R2C and N=4097 C2R. The cleanup grouped inverse-scatter arguments in a private struct; its arithmetic and timing loops did not change. The original six-process phase capture records the exact source and binary hashes used for its measurements.
