## M1: one bounded source-level adapter — completed

1. **Keep the existing order-major queue and cached E/B-to-scalar conversion**. Expose a private prepared-component function from `scalar_ordered.rs` accepting **prepared scalar coefficients** (or one-time per-order preparation), active mirrored pair geometry/index map and caller-owned scratch; *not* a new transform scheduler. Preserve the already working scalar API and its tests.
2. Pack **one 256-pair active north/south index set per m**, honoring both hemisphere eligibility, CC poles, F1 half-offset, equator singleton, ring m limits, phase and Nyquist. Precompute cosine-squared using cancellation-resistant formula near poles. Reuse ring packing/geometry for both converted components.
3. Prepare scalar factors **once per m**, then two component coefficient-pair arrays with the existing checked `prepare_synthesis_coefficient_pair`. Process **Q then U** using the *same packed rings*, with the ordinary SIMD suffix using **four accumulators per pass**, not simultaneous eight live parity sums. Accumulate even and odd separately and reconstruct `north/south = even ± cosθ*odd` once after the component pass, then apply `1/sinθ` and write both components to the existing order-owned q/u scratch.
4. **Safety:** DUCC's `1e-4` conversion threshold is not permission to relax Rust's ~`0.01` ordinary eligibility. Use existing scaled-prefix/checked state and original-E/B polar/unsafe fallback. If either channel declines, do not expose partially completed q/u rows: discard/reinitialize affected **order-owned staged results** and fall back via verified original path. Keep nonfinite and subnormal classification. Do not silently skip valid tiny contributions.
5. **Avoid the old failure mode:** existing rejected adapter called the **high-level scalar ordered transform twice** and regressed T720 CC q8 `15.056→24.029 ms`. The new helper must reuse each order's conversion, packing, scratch and output ownership, calling **only** the internal optimized recurrence twice. If implementation degenerates to two full transform passes, stop before benchmarking.
6. One **CC T720 full q8** release correctness/reference/poison/adjoint gate and one brief, matched original Rust/candidate Rust/DUCC whole-transform A/B. If gain, then quarter q8, q1, F1/GL full q8, T1023 holdout. If slower, investigate **one** measured cause (register spills, extra coefficient preparation/packing, fallback share, memory scatter), one focused correction, then reject. No extended sweep and no test/methodology refactor unless correctness requires it.
